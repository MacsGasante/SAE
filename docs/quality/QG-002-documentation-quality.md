# QG-002 — Documentation Quality

Status: Approved

Owner: Repository

Applies to:

Entire Repository

---

# Purpose

Documentation is considered a first-class engineering artifact.

Repository documentation must evolve together with source code.

---

# Requirements

Documentation must be:

- accurate
- discoverable
- version controlled
- reviewed
- consistent

---

# Repository Rule

Every new public component must include:

- implementation

- tests

- documentation

before being considered complete.

---

# Documentation Rule

Documentation must explain:

Why

What

How

rather than repeat the implementation.

---

# Quality Principle

Good documentation reduces future maintenance cost.

Missing documentation increases technical debt.
