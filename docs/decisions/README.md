# Architectural Decisions

## Purpose

This section indexes Architectural Decision Records (ADR).

Every significant architectural decision affecting the project should be documented as an ADR.

## Principles

- Decisions are immutable.
- Decisions are numbered.
- Decisions are never rewritten.
- Future changes are introduced through new ADRs.

## Examples

- Domain Model evolution
- Kernel architecture
- Layering rules
- Dependency policies
